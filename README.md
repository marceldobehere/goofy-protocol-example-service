# Goofy IRC (Goofy Protocol Example Service)

WIP Example of a Service using the [Goofy Protocol](https://github.com/marceldobehere/goofy-protocol).

Planning for it to be a simple IRC like chat (public, unencrypted but signed messages) with a basic DM system (maybe encrypted).

Basically just to have a minimal base to base other services on that is easy to understand but also uses some of the FIS / Goofy Protocol parts.

This repo will contain a static [NextJS Frontend](./goofy-irc-fe/) and a [Java Backend](./goofy-irc-be/).


**NOTE**: This is WIP in the same time as my [FIS](https://github.com/marceldobehere/goofy-protocol-fis).
